# Portal

## How to setup

### Prerequisites:

- MongoDB Community Server.

- Node.js.

### Clone the repository

```         
git clone https://github.com/bbksu/Portal
```

## Backend

### Setup the Backend

``` bash
cd .Backend
npm install
```

### Start the Backend

``` bash
npm run start
```

## Frontend

### Setup the Frontend

``` bash
cd Frontend
npm install
```

### Start the Frontend

``` bash
npm run start
```

Paste and Go to `https://localhost` or `https://localhost:443` in the browser
